# Fuse ⚡

> **Modern file reassembly for `rclone` chunked files.**

Fuse is a lightweight, cross-platform desktop application built with Go and Fyne. It automatically detects and reconstructs split files generated by `rclone`'s chunker overlay (e.g., `video.mp4.rclone_chunk.001`, `video.mp4.rclone_chunk.002`) back into their original single file seamlessly.

---

## ✨ Features

* **Drag & Drop UI:** Inspired by modern file-sharing interfaces like Blip.
* **Smart Auto-Discovery:** Simply drop *any* single chunk, and Fuse automatically finds, sorts, and verifies all matching pieces in the same folder.
* **Safe Streaming:** Memory-efficient buffered streaming engine that handles multi-gigabyte files smoothly with progress tracking.
* **Atomic Merge & Verification:** Merges into a temporary file first and verifies total size before finalizing to prevent corruption.
* **Automatic Cleanup:** Option to automatically delete source chunk files after a successful merge.
* **Dark Mode Native:** Tailored minimal dark interface out of the box across all platforms.

## Building and Packaging

### 1. Run / Development Mode

To run the application directly without creating an installer/binary package:

```bash
go run .
```

---

### 2. Packaging for macOS (Darwin)

To build a native macOS `.app` bundle:

```bash
fyne package -os darwin -icon icon.png
```

*If `fyne` is not found globally, use the explicit binary path:*
```bash
~/go/bin/fyne package -os darwin -icon icon.png
```

---

### 3. Packaging for Windows from macOS

Because Fyne uses OpenGL bindings (CGO), cross-compiling requires proper C toolchains.

#### Method A: Using `fyne-cross` via Docker (Recommended)

1. **Install Docker Desktop** on your Mac and start it.
2. **Install `fyne-cross`**:
   ```bash
   go install github.com/fyne-io/fyne-cross@latest
   ```
3. **Build the Windows `.exe`**:
   ```bash
   ~/go/bin/fyne-cross windows -icon icon.png
   ```
   *The resulting `.exe` and assets will be output in `fyne-cross/bin/windows/`.*

#### Method B: Direct MinGW Compilation (No Docker)

1. **Install MinGW cross-compiler**:
   ```bash
   brew install mingw-w64
   ```
2. **Compile the Windows executable**:
   ```bash
   GOOS=windows GOARCH=amd64 CGO_ENABLED=1 CC=x86_64-w64-mingw32-gcc go build -ldflags "-H=windowsgui" -o ChunkMerger.exe
   ```
   *(The `-ldflags "-H=windowsgui"` flag hides the terminal window in Windows when running the GUI app).*

---

### 4. Packaging for Linux

Using `fyne-cross`:

```bash
~/go/bin/fyne-cross linux -icon icon.png
```

## Troubleshooting

### `zsh: command not found: fyne`
If running `fyne` fails, your Go binary folder isn't in your `PATH`. Either run using `~/go/bin/fyne` or fix your permissions/PATH:
```bash
sudo chown $USER ~/.zshrc
echo 'export PATH="$PATH:$HOME/go/bin"' >> ~/.zshrc
source ~/.zshrc
```

### `[✗] engine binary not found in PATH`
This occurs when using `fyne-cross` without Docker installed or running. Launch **Docker Desktop** on your machine and ensure `docker info` works in your terminal.
